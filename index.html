      Bab 02 — Penyimpanan File

      04

      Rapi itu soal nama folder.

      1. 1

        Pisahkan surat keluar & masuk

        Dua folder berbeda. Nomor surat punya foldernya sendiri supaya penomoran tidak bentrok dan mudah dilacak.

      2. 2

        Satu kepanitiaan, satu folder

        Buat folder nama kegiatan dulu, baru pecah per peran: sekretaris, bendahara, dan progress tiap sie.

      3. 3

        Jangan ada file nyasar

        Semua dokumen masuk struktur ini — bukan di chat, bukan di Downloads. Satu sumber, semua orang tahu ke mana mencari.

      Struktur folder akar → kegiatan → peran

      Bab 03 — Pembuatan Surat

      05

      Surat yang benar, sekali jadi.

      Jenis surat

      • Pemberitahuan, peminjaman, permohonan, pernyataan, undangan.
      • Template dan contoh ada di folder kepanitiaan sebelumnya.
      • Revisi surat lewat kemahasiswaan.

      Tanda tangan

      • Umumnya Ketua Panitia dan Dosen (Wakil Rektor III).
      • Cantumkan nama dan NIDN/NIM sesuai format.
      • Cek nomor, lampiran, dan perihal sebelum dikirim.

      Bab 04 — LPJ Kegiatan

      06

      LPJ Kegiatan.

      01

      Pembuatan

      Dibuat sebagai pelaporan bahwa kegiatan telah berhasil dilaksanakan. Umumnya disimpan di folder kepanitiaan bagian sekretaris.

      ~/Kepanitiaan/Sekretaris/LPJ

      02

      Isi dari LPJ

      • LPJ Pelaksana
      • LPJ Per Sie
      • Lampiran: nota, absensi, BA, dokumentasi, dll.
      03

      Tenggat

      Wajib selesai dan dikirim ke kemahasiswaan maksimal H+7. Paling telat H+14.

      H+0 H+7 H+14

      Catatan Dicicil dari awal kegiatan lebih baik.

      Target Achieved

      Rangkuman

      07

      Sebelum bubar.

      • Surat masuk dan keluar disimpan terpisah, nomor surat di foldernya sendiri.

      • Struktur folder ikut nama kepanitiaan: Sekretaris, Bendahara, Per Sie.

      • Pakai template surat dari kepanitiaan sebelumnya, revisi lewat kemahasiswaan.

      • Cek format tanda tangan dan siapa yang menandatangani.

      • LPJ dicicil dari awal. Kirim maksimal H+7, paling telat H+14.
